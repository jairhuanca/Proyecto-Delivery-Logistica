# Sistema de Logística y Rutas de Entrega 

Este proyecto es una plataforma web integral enfocada en la gestión logística y el control de rutas de entrega. La arquitectura está dividida en un enfoque Full Stack, separando la lógica del servidor (Backend) de la interfaz de usuario (Frontend), lo que permite una mayor escalabilidad y facilidad de mantenimiento.

## Arquitectura del Proyecto

El repositorio está estructurado en módulos principales para separar las responsabilidades del sistema:

*   **`BackendDelivery/`**: Contiene la lógica del lado del servidor, gestión de base de datos, configuración de la API y procesamiento de algoritmos de rutas.
*   **`FrontendDelivery/`**: Contiene la interfaz de usuario, diseño visual (paleta de colores actualizada) y la interacción del cliente con el sistema.
*   **Recursos Estáticos (`/imágenes`)**: Directorio para los assets visuales y gráficos utilizados en la aplicación.

## Tecnologías Utilizadas

*   **Lenguaje Principal:** JavaScript (JS)
*   **Estructura y Estilos:** HTML5, CSS3
*   **Paradigma:** Arquitectura Cliente-Servidor (Full Stack).

## Características Principales

*   **Interfaz Dinámica:** Frontend actualizado con un sistema de diseño consistente.
*   **Gestión Backend:** Control robusto de los datos de logística y entregas.
*   **Separación de Conceptos:** Estructura de carpetas limpia que facilita el trabajo en equipo y la escalabilidad del software.
